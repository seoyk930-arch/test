# PWM (Pulse Width Modulation)

## 1. 개요

PWM은 펄스의 폭을 조절하여 평균 전압을 제어하는 방식입니다.

## 2. 주요 변수

- 주파수
- 주기
- 듀티비

## 3. 듀티비

듀티비는 전체 주기에서 HIGH 상태가 차지하는 비율입니다.

```text
Duty Cycle = HIGH 시간 / 전체 주기 × 100
```

| 듀티비 | 출력 특성 |
|---|---|
| 25% | 평균 출력이 낮음 |
| 50% | 평균 출력이 중간 |
| 75% | 평균 출력이 높음 |
